01 filter_vcf() — the bcftools pipeline

The most structurally complex function in the file. It sets up four subprocesses piped together and handles deadlock prevention.

filter_vcf() Lines ~169–254 · building and running the four-stage pipeline 
def filter_vcf(src, dst, pass_only, min_dp, min_af, max_gnomad):

    cmd1 = ["bcftools", "view", str(src)]
    if pass_only:
        cmd1 += ["-f", "PASS"]             ①
    cmd1 += ["-Ou"]                         ②

    cmd2 = ["bcftools", "filter",
            "-e", f"(FORMAT/DP<{min_dp} || AF<{min_af})",  ③
            "-Ou"]

    cmd3 = ["bcftools", "+split-vep",
            "--columns", "-",              ④
            "-a", "CSQ",                   ⑤
            "-p", "CSQ_",                  ⑥
            "-s", "worst",                 ⑦
            "-Ou"]

    cmd4 = ["bcftools", "view"]
    if max_gnomad < 1.0:
        gnomad_fields = _csq_gnomad_fields(src)    ⑧
        if gnomad_fields:
            clause = " || ".join(
                f"CSQ_{f}>={max_gnomad}" for f in gnomad_fields)  ⑨
            cmd4 += ["-e", clause]
    cmd4 += ["-Oz", "-o", str(dst)]          ⑩

    p1 = subprocess.Popen(cmd1,
            stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    p2 = subprocess.Popen(cmd2, stdin=p1.stdout,  ⑪
            stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    p1.stdout.close()                             ⑫
    p3 = subprocess.Popen(cmd3, stdin=p2.stdout,
            stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    p2.stdout.close()
    p4 = subprocess.Popen(cmd4, stdin=p3.stdout,
            stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    p3.stdout.close()

    stderr_collectors = {p: [] for p in (p1, p2, p3)}  ⑬
    drain_threads = [
        threading.Thread(target=_drain_stderr,
                         args=(p.stderr, stderr_collectors[p]))
        for p in (p1, p2, p3)
    ]
    for t in drain_threads: t.start()       ⑭

    _, p4_err = p4.communicate()               ⑮
    for t in drain_threads: t.join()          ⑯
    p1.wait(); p2.wait(); p3.wait()            ⑰

    for proc, name in [(p1,"view"),(p2,"filter"),(p3,"split-vep"),(p4,"view/gnomAD")]:
        if proc.returncode != 0:             ⑱
            stderr = b"".join(stderr_collectors.get(proc, []))
            raise RuntimeError(...)

    _run(["bcftools", "index", "-t", str(dst)])  ⑲
①
-f PASS is only added to cmd1 when pass_only=True. When --include-non-pass is set, pass_only is False and bcftools view runs without any filter flag — all variants pass through regardless of FILTER status.
②
-Ou means "output uncompressed BCF". Intermediate pipeline stages use -Ou (uncompressed BCF) instead of -Oz (bgzipped VCF) because BCF is faster to write and read in a pipe — it avoids compression/decompression overhead between stages. Only the final output (cmd4) uses -Oz.
③
The -e (exclude) expression uses || not &&. The expression FORMAT/DP<99 || AF<0.03 removes a variant if either condition is true. A variant needs both high depth AND high VAF to be kept. Note: inside an f-string, < is a literal less-than character — it does not need HTML escaping here (that's only in HTML contexts).
④
--columns - means "extract all available CSQ subfields". The - is a special value that tells split-vep to use the format string from the VCF header itself, extracting all fields defined there. This is more robust than listing field names explicitly, which would need updating whenever the VEP config changes.
⑤
-a CSQ specifies the annotation tag name. The VEP annotation in Uranus pipeline VCFs is stored in an INFO field called CSQ. This tells split-vep which INFO field to parse. Other pipelines might use ANN or BCSQ.
⑥
-p CSQ_ sets the prefix for extracted field names. Each extracted CSQ subfield becomes a new INFO tag with this prefix. So the VEP field gnomADg_AF becomes the INFO tag CSQ_gnomADg_AF, and SYMBOL becomes CSQ_SYMBOL. This prefix is why load_vcf() queries %INFO/CSQ_SYMBOL.
⑦
-s worst picks one transcript per variant. VEP annotates each variant with consequences for every overlapping transcript. Without -s worst, split-vep would emit one output row per transcript, creating duplicate variant rows. worst selects the transcript with the most severe consequence (e.g. stop_gained over synonymous_variant).
⑧
_csq_gnomad_fields(src) is called on the original VCF, not the filtered intermediate. The split-vep stage has not run yet, so the gnomAD fields are still in the CSQ string — we need to inspect the original to know which fields to filter on in Stage 4.
⑨
Building the filter clause dynamically. If both gnomADg and gnomADe fields exist, clause becomes "CSQ_gnomADg_AF>=0.40 || CSQ_gnomADe_AF>=0.40". If only gnomADe exists, it becomes "CSQ_gnomADe_AF>=0.40". The generator expression creates one condition per field; " || ".join() combines them. A variant is removed if either gnomAD field meets the threshold.
⑩
-Oz is bgzipped VCF output; -o dst writes to file. Only the last stage writes to disk — all intermediate stages use -Ou (pipes). The -o flag makes bcftools write output to the file path rather than stdout. If -o were omitted, the output would flow to stdout and then disappear into the pipe's stdout which nobody is reading.
⑪
stdin=p1.stdout connects the processes. p2's standard input is connected to p1's standard output. The OS routes bytes from p1's output pipe directly into p2's input pipe in memory — no temporary file is written to disk.
⑫
p1.stdout.close() in the parent process after handing it to p2. The parent process has inherited a file descriptor for p1's stdout. Closing it in the parent means that when p2 has finished reading, the last writer (p1) can exit cleanly and p2 receives EOF. If the parent keeps it open, p2 might wait forever for data that will never come because p1 has already finished.
⑬
Dict comprehension creating a collector list for each process. {p: [] for p in (p1, p2, p3)} creates a dict mapping each Popen object to an empty list. _drain_stderr() will append the read bytes to this list. Using a list (rather than a single variable) is necessary because Python closures capture by reference — the thread function receives the list reference and appends to it.
⑭
t.start() launches each drain thread immediately. The threads begin reading from stderr as soon as they start. If you delayed starting them, the subprocesses might fill their stderr buffers before the threads begin draining, causing a deadlock. Starting all three before the main thread calls p4.communicate() ensures draining begins immediately.
⑮
p4.communicate() blocks until p4 finishes. This is the main thread's only blocking call. It reads all of p4's stdout (discarded with _) and stderr, then waits for p4 to exit. Because p4's input comes from p3, and p3's from p2, and p2's from p1, finishing p4 means the whole pipeline has finished.
⑯
t.join() waits for each drain thread to finish. The drain threads are reading from p1/p2/p3's stderr. Once those processes have exited (which they have, since p4 has finished), the threads will reach EOF and return. join() ensures they have fully finished before the code reads from stderr_collectors.
⑰
p1.wait(); p2.wait(); p3.wait() — cleaning up zombie processes. Even though all processes have logically finished, on Unix each process stays as a zombie in the process table until the parent calls wait(). Without this, the OS keeps process table entries open. This is good hygiene, especially for tools that process many samples.
⑱
Return codes are checked after all processes have finished. This ordering is critical. Checking p1.returncode while p2/p3/p4 are still running could cause a deadlock if p1's stderr buffer was full and needed draining before it could exit. By checking return codes only after all processes and drain threads have finished, the code is safe.
⑲
Tabix indexing is only performed after all stages confirm success. If any stage failed, a RuntimeError was raised at annotation ⑱ and this line is never reached. This ensures a broken filtered VCF is never indexed — otherwise the .tbi file would exist, the cache check in main() would consider it valid, and the broken VCF would be silently reused on the next run.

02 _find_peaks() — the histogram algorithm

_find_peaks() Lines ~319–370 · complete function 
def _find_peaks(log2_ratios: np.ndarray, bin_width: float) -> dict:

    result = {
        "overall_log2": float("nan"), "overall_count": 0, ...  ①
        "nonunity_log2": float("nan"), "nonunity_count": 0, ...
    }

    if len(log2_ratios) == 0:            ②
        return result

    edges = np.arange(
        -_LOG2_RANGE - bin_width / 2,   ③
         _LOG2_RANGE + bin_width,
         bin_width,
    )
    counts, edges = np.histogram(log2_ratios, bins=edges)  ④
    centers = (edges[:-1] + edges[1:]) / 2.0             ⑤
    n_total = len(log2_ratios)

    if counts.max() == 0: return result  ⑥

    idx_overall = int(np.argmax(counts))  ⑦
    result["overall_log2"]    = float(centers[idx_overall])
    result["overall_count"]   = int(counts[idx_overall])
    result["overall_fraction"] = float(counts[idx_overall]) / n_total

    nonunity_mask = np.abs(centers) > 0.3      ⑧
    nonunity_counts = counts.copy()              ⑨
    nonunity_counts[~nonunity_mask] = 0          ⑩

    if nonunity_counts.max() > 0:
        idx_nonunity = int(np.argmax(nonunity_counts))  ⑪
        result["nonunity_log2"]    = float(centers[idx_nonunity])
        result["nonunity_count"]   = int(counts[idx_nonunity])   ⑫
        result["nonunity_fraction"] = float(counts[idx_nonunity]) / n_total

    return result
①
Initialise all result keys to NaN/0 before computing anything. This guarantees the return dict always has all expected keys, even if the function returns early. Callers can use result["nonunity_count"] without a KeyError regardless of what happened inside.
②
Guard against empty input. If the merged DataFrame had zero shared variants (which _compare() prevents by returning early, but defensive programming here), return the all-NaN dict immediately.
③
The bin edges are centred correctly. Starting at -_LOG2_RANGE - bin_width/2 = -4.1 ensures that a log2 ratio of exactly 0.0 falls in the centre of its bin rather than on a bin boundary. If a ratio cluster sits exactly on a boundary it would be split between two adjacent bins, weakening the peak signal.
④
np.histogram() returns two arrays. counts has one element per bin (how many values fell in it). edges has N+1 elements (the boundaries). The second return value replaces the input edges variable — this is fine because numpy may adjust the edge values slightly for floating-point precision.
⑤
Computing bin centres with array slicing. edges[:-1] is all edges except the last (N elements: left boundaries). edges[1:] is all edges except the first (N elements: right boundaries). Adding them and dividing by 2 gives the midpoint of each bin. This is a standard numpy idiom.
⑥
Guard against all-zero counts. If all ratios were outside the -_LOG2_RANGE to +_LOG2_RANGE window, every bin would be empty. This cannot happen with real data (log2 ratios of values close to 1 always fall near 0) but the guard prevents a confusing result.
⑦
int(np.argmax(counts)) — the index of the tallest bin. np.argmax() returns a numpy integer; wrapping in int() converts it to a plain Python integer. This matters because numpy integers don't always behave identically to Python ints in all contexts (e.g. JSON serialisation). The same float() and int() pattern appears throughout for this reason.
⑧
np.abs(centers) > 0.3 creates a boolean array mask. For each bin centre, this is True if the bin is outside the unity zone (|log2| > 0.3) and False if it is inside. The 0.3 threshold corresponds to a ratio range of 0.81–1.23, which captures measurement noise at the minimum panel depth (see Part 3, concept 1).
⑨
counts.copy() — creating a modified copy, not modifying the original. The next line will zero out the unity zone bins. If we modified counts directly, the overall peak values computed above would be wrong. By working on a copy, the original counts array remains intact for reading at annotation ⑫.
⑩
nonunity_counts[~nonunity_mask] = 0 — masking the unity zone. ~nonunity_mask is the boolean NOT — True where the bin IS in the unity zone. Setting those bins to 0 means np.argmax(nonunity_counts) will never select a unity-zone bin. The contamination peak is always the tallest bin outside this masked region.
⑪
Finding the tallest non-unity bin. np.argmax(nonunity_counts) finds the index of the tallest remaining bin (unity zone bins are zeroed). This index is then used to retrieve the centre position and the count from the respective arrays.
⑫
int(counts[idx_nonunity]), not nonunity_counts[idx_nonunity]. The count comes from the original (unmasked) array. For non-unity bins, the values are identical — the mask only zeroed unity-zone bins. But using the original array makes the intent explicit: we want the actual count of variants in this bin, not a potentially-modified value.

03 _compare() — core pairwise comparison

_compare() Lines ~373–465 · merge, ratios, peaks, directionality 
def _compare(name_a, df_a, name_b, df_b, bin_width,
             include_shared_df=False):

    merged = pd.merge(
        df_a[[...]] .rename(columns={"af": "af_a", "filter_col": "filter_a"}),
        df_b[[...]] .rename(columns={"af": "af_b", "filter_col": "filter_b"}),
        on=["chrom", "pos", "ref", "alt"], how="inner",
    )                                              ①
    n_shared = len(merged)

    nan = float("nan")
    result = {"sample_a": name_a, "sample_b": name_b,
              "n_shared": n_shared, ...}          ②

    if n_shared < 2:
        return result, None                      ③

    merged = merged[(merged["af_a"] > 0) & (merged["af_b"] > 0)].copy()  ④
    n_valid = len(merged)
    if n_valid < 2: return result, None

    result["n_shared"] = n_valid                 ⑤

    ratios = merged["af_b"] / merged["af_a"]
    merged["ratio"]      = ratios.values          ⑥
    merged["log2_ratio"] = np.log2(ratios.values)

    peaks = _find_peaks(merged["log2_ratio"].values, bin_width)

    result.update({
        "overall_log2": peaks["overall_log2"],
        "overall_ratio": 2.0 ** peaks["overall_log2"]
            if not math.isnan(peaks["overall_log2"]) else nan,  ⑦
        ...
    })

    plr = peaks["nonunity_log2"]
    if not math.isnan(plr) and peaks["nonunity_count"] > 0:
        half = bin_width / 2.0
        merged["in_peak"] = (
            (merged["log2_ratio"] >= plr - half) &  ⑧
            (merged["log2_ratio"] <= plr + half)
        )
        if plr < 0:                               ⑨
            result.update({
                "contamination_source":    name_a,
                "contamination_recipient": name_b,
                "contamination_fraction":  2.0 ** plr,  ⑩
            })
        else:
            result.update({
                "contamination_source":    name_b,
                "contamination_recipient": name_a,
                "contamination_fraction":  2.0 ** (-plr),
            })
    else:
        merged["in_peak"] = False                ⑪

    return result, (merged if include_shared_df else None)  ⑫
①
The inner merge finds shared variant positions. Only rows present in both DataFrames (matching on all four of chrom, pos, ref, alt) are kept. The rename() calls happen before the merge so the resulting DataFrame has unambiguous column names: af_a and af_b rather than af_x and af_y (which pandas would create automatically for duplicate column names).
②
The result dict is populated with default NaN values immediately. This guarantees a complete, well-formed dict is always returned — even if the function exits early. Callers and the DataFrame constructor downstream can rely on all keys always being present.
③
Early return for insufficient shared variants. With fewer than 2 shared variants, there is no histogram to compute. The None second return value signals "no shared DataFrame available". _worker() discards this with _ anyway.
④
Filter out zero-AF variants and call .copy(). Division by zero would produce inf or NaN in the ratio. The .copy() is critical: pandas raises a SettingWithCopyWarning if you assign a new column to a slice of a DataFrame. Calling .copy() makes merged an independent DataFrame, not a view, so the subsequent merged["ratio"] = ... assignment is safe.
⑤
Update n_shared to the valid (non-zero-AF) count. The initial n_shared = len(merged) before filtering was the count including zero-AF variants. After filtering, the count may be lower. Updating the result dict here means the reported n_shared reflects the variants actually used in the histogram.
⑥
.values extracts the numpy array from a pandas Series. merged["af_b"] / merged["af_a"] returns a pandas Series. Using .values on the result gives a plain numpy array, which is slightly faster for np.log2() than passing a Series directly. The ratios are stored in the DataFrame as a new column for later use in the detail TSV.
⑦
Conditional power-of-2 conversion with NaN guard. 2.0 ** float("nan") would produce NaN rather than raising an error, but using math.isnan() makes the intent explicit: "only convert to a ratio if a peak was found". The ternary expression X if condition else Y is Python's inline if-else.
⑧
Marking variants within the non-unity peak bin. A variant is "in the peak" if its log2 ratio is within half a bin-width of the peak centre. These are the variants that constitute the contamination signal. They appear in the detail TSV and are highlighted in histogram plots, making it easy to inspect which specific variants drove the flagging.
⑨
Directionality from the sign of plr. If plr < 0, VAF_B < VAF_A — sample A's variants appear diluted in sample B, so A is the source. If plr > 0, the reverse. This is the most clinically important output: it tells the lab which sample contaminated which.
⑩
Contamination fraction estimate: 2.0 ** plr. If plr = -1.0 (peak at log2 = -1), the ratio is 0.5, meaning the recipient's variants appear at half the source VAF. The contamination fraction is therefore ~50%. More precisely, for a germline het source at VAF 0.5, VAF_recipient = 0.5 × contamination_fraction, so contamination_fraction = VAF_recipient / 0.5 = ratio. For negative plr: 2^plr = ratio, which is between 0 and 1.
⑪
Set in_peak=False for all variants when no peak was found. This column must always exist in the merged DataFrame so downstream code can reference it without checking. When there is no contamination peak, all variants are marked as not-in-peak.
⑫
Conditional return of the shared DataFrame. merged if include_shared_df else None is Python's ternary operator. In Phase 3 (via _worker()), include_shared_df=False and None is returned — saving the memory of holding thousands of DataFrames. In Phase 4's second pass for flagged pairs, include_shared_df=True and the full DataFrame is returned for detail output.

def _apply_flags(results, min_shared, peak_count_thresh,
                  n_shared_z_thresh, freemix=None, freemix_threshold=0.15):

    df = pd.DataFrame(results)              ①

    n_mean = df["n_shared"].mean()
    n_std  = df["n_shared"].std()
    df["n_shared_z"] = (
        (df["n_shared"] - n_mean) / n_std  ②
        if n_std > 0 else 0.0              ③
    )

    base_flag = (
        (df["n_shared"]   >= min_shared)        ④
      & (df["peak_count"] >= peak_count_thresh)
      & (df["n_shared_z"] >= n_shared_z_thresh)
    )

    if freemix is not None:
        df["recipient_freemix"] = \
            df["contamination_recipient"].map(freemix)  ⑤
        freemix_flag = df["recipient_freemix"] >= freemix_threshold

        n_missing = df.loc[base_flag, "recipient_freemix"].isna().sum()
        if n_missing:
            logging.warning("...")                ⑥

        df["flagged"] = base_flag & freemix_flag.fillna(False)  ⑦
    else:
        df["flagged"] = base_flag               ⑧

    for col in ["overall_log2", "peak_log2_ratio", ...]:
        if col in df.columns:
            df[col] = df[col].round(4)           ⑨

    return df
①
pd.DataFrame(results) converts a list of dicts to a DataFrame. Each dict in the list becomes one row. The keys become column names. pandas infers types automatically — integer values become int64, float values become float64, NaN values are handled correctly. This is the standard pandas pattern for collecting results from loops.
②
Vectorised z-score computation across all pairs. df["n_shared"] - n_mean subtracts the mean from every value simultaneously (broadcasting). Dividing by n_std normalises. This single expression computes z-scores for potentially thousands of rows in microseconds — far faster than a Python loop.
③
Guard against zero standard deviation. If all pairs have identical n_shared (which would happen in a run with exactly 2 samples, giving only 1 pair), n_std is 0 and division would produce NaN. The if n_std > 0 else 0.0 conditional sets all z-scores to 0.0 in this edge case, preventing NaN from propagating to the flagged column.
④
The compound boolean flag using & (not and). Each condition in parentheses produces a boolean pandas Series. The & operator applies element-wise AND across all three Series simultaneously, producing a single boolean Series where True means all three conditions are met for that pair. Python's and keyword cannot be used here — it operates on single values, not Series.
⑤
.map(freemix) — a vectorised dictionary lookup. For each sample name in the contamination_recipient column, .map() looks it up in the freemix dict and returns the corresponding FREEMIX value. Sample names not in the dict get NaN. This is equivalent to writing freemix.get(name, None) for each row but vectorised across the entire column.
⑥
Warning for base-flagged pairs with no FREEMIX data. df.loc[base_flag, "recipient_freemix"].isna().sum() counts how many pairs that passed the peak/z thresholds have no FREEMIX data for their recipient. These pairs will not be flagged (because of the fillna(False) in the next line). The warning alerts the user so they can investigate why FREEMIX data is missing for those samples.
⑦
freemix_flag.fillna(False) makes missing FREEMIX conservative. If FREEMIX data is missing for a sample, freemix_flag is NaN for that row. NaN & True is NaN in pandas (not False), so without fillna(False), pairs with missing FREEMIX could become NaN in the flagged column. fillna(False) converts any NaN to False — the conservative choice is to not flag a pair when you cannot confirm the FREEMIX threshold.
⑧
When no FREEMIX file is provided, base_flag is the final flag. The FREEMIX gate is entirely optional. Without it, only the three base conditions (n_shared, peak_count, n_shared_z) determine flagging. The recipient_freemix column is simply absent from the output.
⑨
Rounding float columns to 4 decimal places before output. Without rounding, floating-point arithmetic produces values like -0.9999999999999998 instead of -1.0. The if col in df.columns guard handles the case where FREEMIX columns are absent — trying to round a non-existent column would raise a KeyError.

05 Bonus: _csq_gnomad_fields()

_csq_gnomad_fields() Lines ~156–166 · complete function 
def _csq_gnomad_fields(src: Path) -> List[str]:
    result = subprocess.run(
        ["bcftools", "+split-vep", "-l", str(src)],
        capture_output=True, text=True,    ①
    )
    if result.returncode != 0:
        return []                           ②
    available = {
        line.split("\t")[1]               ③
        for line in result.stdout.strip().splitlines()
        if "\t" in line
    }
    return [f for f in ("gnomADg_AF", "gnomADe_AF") if f in available]  ④
①
capture_output=True, text=True is shorthand for stdout=PIPE, stderr=PIPE plus automatic UTF-8 decoding. result.stdout is already a string (not bytes). This is available in Python 3.7+.
②
Return an empty list on failure. If split-vep fails (wrong bcftools version, no CSQ tag), returning [] causes filter_vcf() to skip the gnomAD filter entirely and log a warning. The pipeline continues without the gnomAD filter rather than crashing — a graceful degradation.
③
Set comprehension to build field names. Each line of bcftools +split-vep -l output is "index<TAB>field_name". line.split("\t")[1] extracts the second column (the field name). Using a set (curly braces) automatically deduplicates. The if "\t" in line guard skips any blank lines or header lines without a tab.
④
List comprehension that preserves the preferred field order. The tuple ("gnomADg_AF", "gnomADe_AF") specifies the order — gnomADg first. The comprehension returns only fields that are actually present in available. For newer VCFs both are returned; for older VCFs only gnomADe_AF; for VCFs with neither field, an empty list is returned.

for line in r.stdout.decode().splitlines():
    if not line: continue
    parts = line.split("\t")
    if len(parts) < 6: continue                          ②
    chrom, pos_s, ref, alt, filt, af_s = parts[:6]       ③
    gene = parts[6].strip() if len(parts) > 6 else ""   ④
    if gene == ".": gene = ""                             ⑤
    try:

①
The bcftools query format string. Each %TOKEN is replaced by the corresponding VCF field. %CHROM, %POS, %REF, %ALT are VCF INFO columns. %FILTER is the filter status. [%AF] in square brackets means "sample-level FORMAT field AF" — the square brackets are bcftools syntax for accessing FORMAT fields per sample. %INFO/CSQ_SYMBOL accesses the CSQ_SYMBOL INFO field created by split-vep. Fields are separated by \t and each variant ends with \n.
②
Skip lines with fewer than 6 fields. A well-formed bcftools query line has at least 6 tab-separated fields (chrom through AF). Lines with fewer fields could indicate a malformed variant or an unexpected header line. Silently skipping them is safer than crashing.
③
Tuple unpacking from a list slice. parts[:6] takes the first 6 elements. Assigning to six variable names on the left simultaneously unpacks them. This is cleaner than chrom = parts[0]; pos_s = parts[1]; ... and less error-prone.
④
Gene name may or may not be present. If CSQ_SYMBOL was not extracted by split-vep (e.g. an intergenic variant), the field may be absent, making len(parts) equal to 6. The conditional handles this without IndexError. .strip() removes trailing whitespace or carriage returns that bcftools sometimes adds.
⑤
bcftools represents missing values as ".". When CSQ_SYMBOL has no value, bcftools writes a literal dot. Converting it to an empty string "" is cleaner for downstream use — empty string is falsy in Python, making if gene: a clean check.
⑥
Skip variants where AF cannot be parsed as a float. The FORMAT/AF field is occasionally missing or malformed (e.g. "." for variants with no reads). float(".") raises a ValueError. The try/except silently skips these variants rather than crashing the whole load.

07 Bonus: _get_plate_order() — MultiQC well sorting

_get_plate_order() Lines ~550–590 · key sorting logic 
gs = pd.read_csv(plate_file, sep="\t")
col_row = "custom_content_samplesheet_wells-well_row"     ①
col_col = "custom_content_samplesheet_wells-well_column"

gs = gs[~gs["Sample"].str.contains(r"_S\d+_L\d+", na=False)]  ②
gs = gs.dropna(subset=[col_row, col_col])

pos_map = {}
for _, row in gs.iterrows():
    name = row["Sample"]
    if name in sample_names:
        pos_map[name] = (int(row[col_col]), row[col_row])  ③

ordered = sorted(
    [n for n in sample_names if n in pos_map],
    key=lambda n: (pos_map[n][0], pos_map[n][1]),         ④
)
remaining = [n for n in sample_names if n not in pos_map]  ⑤
return ordered + remaining
①
MultiQC column names for plate well position. These long column names come from the custom_content_samplesheet_wells MultiQC module. The hyphenated format is MultiQC's convention for nested module data. If this module is absent or the column names change in a future MultiQC version, the function falls back to returning samples in filename order.
②
Filtering out per-lane FASTQ rows. MultiQC includes rows like SampleName_S1_L001 representing individual sequencing lanes. These have no plate well position. The regex _S\d+_L\d+ matches these lane rows; the ~ negates the match to keep only sample-level rows. na=False treats NaN sample names as not matching.
③
Building the position map as a tuple (column, row_letter). Column is cast to int because it may come in as a float from the DataFrame. Row letter is kept as a string (A, B, C...). The tuple order (column first) is intentional — it drives the sort order: column-major means A1, B1, C1 ... H1, A2, B2 ... which matches how plates are typically read in the lab.
④
Sorting by a tuple key gives column-major plate order. Python's sorted() with a tuple key sorts by the first element, then by the second element for ties. So all column-1 samples sort together (by row letter A→H), then all column-2 samples, etc. This is column-major order — adjacent wells appear adjacent in the output matrix, making contamination between neighbouring wells visible as near-diagonal entries.
⑤
Appending samples not found in the plate file. Some samples may not have plate position data (e.g. control samples that were not on the standard plate layout). These are collected into remaining and appended after the plate-ordered samples. A warning is logged. This ensures no sample is silently dropped from the matrix.
